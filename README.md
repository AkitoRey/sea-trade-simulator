## Описание проекта

Sea Trade Simulator — консольный игровой симулятор, в котором игрок управляет торговой компанией и её морским судном.

В рамках курсового проекта постепенно реализуются классы предметной области и игровая логика. На текущем этапе выполнена лабораторная работа №2, посвящённая классам, агрегации, композиции и ручному управлению памятью в C++.

## Классы лабораторной работы №2

В лабораторной работе реализованы три класса:

- `CrewMember` — член экипажа. Хранит имя, здоровье и состояние болезни/изоляции; умеет получать урон, восстанавливать здоровье, заболевать и изолироваться.
- `Ship` — корабль. Хранит название, грузоподъёмность и текущий груз, а также ссылку на существующего члена экипажа.
- `TradingCompany` — торговая компания. Содержит собственный объект `Ship` и управляет его грузом.

### Связи между классами

**Агрегация:** `Ship` → `CrewMember`.

Член экипажа создаётся отдельно и передаётся кораблю по ссылке. Корабль не создаёт и не уничтожает `CrewMember`. Поэтому после уничтожения корабля член экипажа продолжает существовать.

**Композиция:** `TradingCompany` → `Ship`.

Корабль хранится внутри торговой компании как объект-поле. Он создаётся вместе с компанией и автоматически уничтожается при уничтожении компании.

Таким образом, три класса образуют единую связанную структуру:

`TradingCompany` → `Ship` → `CrewMember`

## Что демонстрирует программа

Демонстрационная программа показывает:

- создание и использование объектов классов;
- инкапсуляцию и работу с `private`-полями через методы;
- проверку правила грузоподъёмности корабля;
- агрегацию и различие времени жизни `Ship` и `CrewMember`;
- композицию и автоматическое уничтожение `Ship` вместе с `TradingCompany`;
- статический объект;
- динамическое создание объекта через `new` и удаление через `delete`;
- работу с объектом по ссылке;
- работу с объектом по указателю;
- динамический массив объектов с `new[]` / `delete[]`;
- массив указателей на динамически созданные объекты;
- вывод сообщений деструкторов для демонстрации времени жизни объектов.

## Сборка и запуск

### Вариант 1: CMake из терминала

Из корневой папки проекта:

```bash
cmake -S . -B build
cmake --build build
```

После успешной сборки запускается исполняемый файл `sea_trade_simulator`.

### Вариант 2: Visual Studio

1. Открыть папку проекта в Visual Studio.
2. Дождаться конфигурации CMake.
3. Выбрать конфигурацию `x64-Debug` или другую доступную конфигурацию.
4. Запустить проект `sea_trade_simulator`.
