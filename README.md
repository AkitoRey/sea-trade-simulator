# Sea Trade Simulator

Курсовой проект: игровой симулятор управления торговым судном
и морскими маршрутами.

- Год: 2026

## Описание

Однопользовательский консольный игровой симулятор с элементами
ролевой игры. Игрок управляет торговой компанией: нанимает
капитана и команду, выбирает судно, закупает товары, прокладывает
морские маршруты, сталкивается со случайными событиями (штормы,
пираты, таможенные досмотры) и взаимодействует с фракциями.

## Технологии

- **C++** (стандарт C++17)
- **ООП** (инкапсуляция, наследование, полиморфизм)
- Сборка: CMake (планируется)
- Формат данных: JSON/XML
- Интерфейс: консоль (ANSI-панели, ASCII/Unicode)
